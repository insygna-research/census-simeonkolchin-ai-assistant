# Мой ассистент

Персональный AI-агент для личного пользования. Умеет переключаться между
LLM-провайдерами и работать с моими сервисами: календарём и напоминаниями iCloud
и Telegram.

## Возможности

- **Выбор LLM на лету** — модель переключается прямо в UI-селекторе, провайдер,
  ключ и base_url подставляются автоматически по префиксу модели:
  - **GigaChat** (`gigachat/…`)
  - **DeepSeek** (`deepseek/…`)
  - **OpenAI** (`openai/…`)
- **iCloud** — календарь и напоминания (через CalDAV):
  создание/просмотр событий, создание и завершение напоминаний.
- **Telegram** — чтение, поиск и отправка сообщений в разрешённых чатах
  (от моего аккаунта).

Интеграции **GitLab / YouGile / Outline** поддерживаются, но сейчас не подключены —
включаются автоматически, если заполнить их ключи в `.env` (пустой ключ = выключено).

> Заметки Apple Notes с сервера недоступны (у Apple нет API) — вместо них
> используются напоминания iCloud с текстом в поле notes.

## Запуск

```bash
docker compose up --build -d
```

Интерфейс: http://localhost:8080

## Настройка (`.env`)

Скопировать `.env.example` в `.env` и заполнить только то, что нужно:

- **LLM** — ключ хотя бы одного провайдера:
  - `DEEPSEEK_API_KEY` / `OPENAI_API_KEY` / `GIGACHAT_CREDENTIALS`
  - `LLM_PROVIDER` — провайдер по умолчанию, модель переключается в UI
- **iCloud** — `ICLOUD_USERNAME` + `ICLOUD_APP_PASSWORD`
  (пароль приложения: appleid.apple.com → Безопасность → Пароли приложений)
- **Telegram** — `TELEGRAM_API_ID` / `TELEGRAM_API_HASH` / `TELEGRAM_PHONE`
  и `TELEGRAM_ALLOWED_CHATS` (список разрешённых чатов; пусто = все чаты)

Любая интеграция с пустым ключом просто не подключается — лишнее можно не заполнять.
